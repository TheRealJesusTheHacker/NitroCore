How it works

Download the .exe from the releases page. No installer, no bundled junk.

Right-click → Run as administrator. Windows tuning needs admin rights — the app tells you if you forget.

Pick a profile, hit Run. Preview mode first if you want to see everything up front.

Done. Every change is logged, and a restore point has your back.

Questions

Is it really free?

Yes. MIT licensed — free forever, source code public. No ads, no upsells, no "pro" tier.

Is it safe?

Preview mode shows every change before it's applied, a restore point is offered before anything risky, and your personal files are never touched. Full FAQ in the README.

Will my antivirus flag it?

Possibly — unsigned system utilities often get false-flagged. Verify your download against the published SHA256 hashes on the releases page. A code-signing certificate is on the roadmap.

Does it spy on me?

No. Zero telemetry, zero network connections. If a NitroCore binary ever phones home, that's a bug — report it.

Which Windows versions?

Windows 10 and 11, 64-bit. The app must run as administrator.
